⚠️ DEVELOPER NOTE (Ethan — remove before production)
Three Sharing Tools: Each affiliate gets all three: a discount code (alphanumeric only, max 8 chars, e.g. WEILIN88), a referral link (shuspot.com/?ref=ID), and a QR code (which simply encodes the referral link URL).

Discount Code Rules: Uppercase A-Z (excluding O, I, L) + digits 0-9 (excluding 0) + optional hyphen. Max 8 characters. Affiliates choose during signup or one is auto-generated. Codes must be unique across all affiliates. These map to Stripe promotion_codes — see Technical Requirements doc for details.

QR Code Generation: Use a server-side QR library (e.g. qrcode npm package) to generate a QR image encoding the affiliate's referral link. Cache the image. The "Download QR" button should serve the cached PNG.

Attribution Priority: If a ShuSpot signup has BOTH a discount code AND a referral link cookie, the discount code wins. See "ShuSpot-Affiliate-Technical-Requirements.docx" Section 6 for the full priority rules.

Why English-only codes: Chinese users' phones default to Pinyin input (which outputs Chinese characters). They need to switch to English keyboard mode to type the code. This is normal — they do it for passwords and emails. But keep codes SHORT and avoid confusing chars (0/O, 1/I/L). The checkout field on shuspot.com should auto-uppercase and strip any non-alphanumeric input.
